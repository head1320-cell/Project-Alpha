# 감사 — 시장 스냅샷 파이프라인은 운영에서도 합성 스냅샷을 만든다 (2026-11-13 · ★읽기 전용 · 제품 코드 0줄★)

> 요청: 야후 시세 mock 게이트를 넣다가 찾은 것을 "읽기 전용 감사부터" 하기로 하셨다. 이 문서는 ★무엇이 어디에 닿는지★만 적는다 — 고치지 않았다.
> 이 문서가 답하는 질문은 **데이터 무결성**(값의 출처)이다. 예측력·경제적 가치와 무관하다.

## 0. 판정

- `src/screener_pipeline.py` 는 mock 게이트(`mock_allowed()`)를 **지나지 않고** 합성값을 만든다. 운영(`KIS_USE_MOCK=0`)의 기본 설정에서
  기동 뒤 5분마다 ★실제 종목코드에 지어낸 값★을 두 표에 쓴다. CLAUDE.md §6 "운영에서는 합성값을 만들지 않습니다"와 §4 "가짜 종목 이름 재도입 금지"에 어긋난다.
- ★화면에는 닿지 않는다★(관측 — 프론트 소스에서 이 값을 읽는 호출 0건). 닿는 곳은 레거시 API 넷과 DB 표 둘이다.
- 응답과 표에 합성이라는 표시가 없다(동등 품질로 위장할 수 있는 폴백 — §4 의 네 조건 가운데 ⑵ 라벨 · ⑶ 위장 불가를 채우지 못한다).

## 1. 범위 · 방법 · 증거 등급

- 방법: 코드 읽기 + ★로컬 실행 관측★(운영 게이트 `KIS_USE_MOCK=0` · 임시 sqlite · 외부 연결 차단 · 야후 선택 스위치 기본값 끔).
- 등급: **관측(로컬 실행 · 코드 경로)**. 운영 DB·운영 로그·실제 API 소비자는 보지 않았다 — 운영에서 누가 이 라우트를 부르는지는 **미상**이다.

## 4. 왜 문제인가 (이 저장소의 규율로)

1. **mock 게이트 밖의 합성값** — "`mock_allowed()` 가 유일한 판정 기준 · 운영에서는 합성값을 만들지 않는다 — 실패하면 `None`/빈값 + 사유 · 새 스토어는 반드시 이 게이트를 통과"(§6).
2. **가짜 이름** — "`\"Unknown Corp\"`·가짜 종목코드 재도입 금지"(§4). 코드는 진짜인데 이름("… Corp")과 업종이 가짜다.
3. **침묵 폴백** — 야후를 켠 운영에서 받기에 실패하면 같은 합성 스냅샷으로 바뀐다. 응답에서는 구별할 수 없다(§4 네 조건 가운데 라벨·위장 불가 미충족).
4. 영향은 **좁다**(화면 0 · 레거시 API 넷). 그래서 급하지는 않지만, API 로 이 값을 받는 쪽이 있으면 실데이터로 읽을 것이다.

## 5. 고침 선택지 (★구현하지 않았다 — 승인 사항★)

| 안 | 무엇을 하나 | 얻는 것 | 치르는 것 |
|---|---|---|---|
| **가. 운영에서는 만들지 않는다** | mock 게이트가 꺼져 있으면 합성 스냅샷을 쓰지 않는다 — equity 는 야후를 켰을 때 받은 것만, FICC 는 원천이 없으므로 비운다. 레거시 라우트는 0건 + 사유. mock 에서는 지금처럼 만들되 응답에 합성 표시 | 불변식(§6)에 맞는다. 변경이 작다 | 운영의 레거시 `POST /screener` 가 FICC 0건 · (야후를 끈 기본 설정이면) equity 0건이 된다 — API 소비자가 있으면 그쪽이 바뀐다(미상) |
| **나. 라벨만 붙인다** | 표와 응답에 합성 표시를 싣는다. 값은 계속 만든다 | 응답으로 구별할 수 있다 | §6 위반은 남는다(운영에서 합성값을 만든다) |
| **다. 레거시 스냅샷 경로를 걷어 낸다** | 파이프라인 · 표 둘 · 레거시 라우트 넷 · 프론트의 쓰이지 않는 API 함수 셋을 지운다 | 가장 깨끗하다(화면 사용처 0 · 시험 0) | 범위가 크고 되돌리기 어렵다. 외부에서 이 API 를 쓰는 곳이 있으면 깨진다(미상). 표 삭제는 DB 마이그레이션이다 |
| **라. 그대로** | 이 문서만 남긴다 | 변경 없음 | 위 네 문제가 남는다 |

**권고: 가.** 불변식에 맞추는 가장 작은 변경이다. 화면이 쓰지 않으므로 사용자 경험은 바뀌지 않는다. 그 뒤에 이 API 를 부르는 곳이 정말 없다고 확인되면 다(걷어 내기)를 따로 결정한다.
- 가를 고르시면 함께 정할 것: ⑴ 야후를 켠 운영에서 일부 종목만 받았을 때(지금은 받은 것만 쓴다 — 그대로 둘지) ⑵ `GET /screener/status` 가 임시 sqlite 에서 500 인 것(운영 DB 에서 재 봐야 한다).

## 6. 하지 않은 것 · 미검증

- 코드를 바꾸지 않았다(트립와이어 시험도 더하지 않았다 — 고침 방향이 정해지지 않았다).
- 운영에서 이 라우트의 호출 기록을 보지 않았다(접근 로그 없음 — 미상).
- 야후를 켠 운영 경로의 값 품질(야후 응답 · 일부 실패 시의 섞임)은 미검증이다.
