# 화면 용어집 · 문체 규칙 (2026-11-11 · ADR 005)

화면에 보이는 글자를 쓸 때 따르는 기준이다. 프론트 소스(`frontend/src`)와 서버가 화면으로 보내는 문장 모두에 걸린다.
지키는지는 `tests/test_frontend_voice.py`(해요체 래칫)와 `frontend/e2e/helpers.ts::voiceAudit` 가 본다.
코드 주석과 문서의 말투는 대상이 아니다.

## 1. 문체

| 자리 | 쓰는 꼴 | 예 |
|---|---|---|
| 라벨 · 제목 · 칩 · 표 머리 | 명사형(개조식) | 수익성 · 괴리율 · 연환산 변동성 |
| 단추 | 동작 명사 | 재계산 · 조회 · 저장 · 실행 · 재시도 · 상세 · 삭제 |
| 상태 | 명사형 | 계산 중 · 조회 실패 · 저장 완료 |
| 설명 · 안내 · 사유 문장 | 합니다체 평서문 | 무위험수익률 3.5%, 베타 1.0 가정으로 산출했습니다. |
| 요청 | ~하십시오 | 값을 입력하십시오. |

- 해요체(~어요·~예요·~세요·~죠·~까요)는 쓰지 않는다. 물음표·느낌표·권유형("~해 봐요")도 쓰지 않는다.
- 예외 둘: ① 되돌릴 수 없는 일을 묻는 **확인 대화상자**는 "~하시겠습니까?"로 쓴다("이 주문을 취소하시겠습니까?"). ② 사용자가 직접 치는 글(AI 에게 묻는 말)과 그 미리 채운 예문은 사용자의 말이라 고치지 않는다.
- 의문형 제목·설정 질문("어떤 조건으로 거를까요?")은 명사형으로 쓴다(`스크리닝 조건`) — §3.5.
- 한 문장에 한 가지만 말한다. 주어가 화면에 이미 보이면 생략한다("현재가가 … 높습니다" → 칩 `괴리율 +75%`).
- 낭독기용 글자(`aria-label`)도 같은 문체다.

## 2. 상태 문구 — 같은 꼴로 쓴다

| 예전 | 지금 |
|---|---|
| X를 불러오는 중이에요 | X 조회 중 |
| 계산하는 중이에요 · 확인하는 중이에요 · 적재하는 중이에요 | 계산 중 · 확인 중 · 적재 중 |
| X를 불러오지 못했어요 | X 조회 실패 |
| X를 계산하지 못했어요 · 내지 못했어요 | X 산출 실패 (모형이 값을 못 내면 `산출 불가` + 사유) |
| X를 재지 못했어요 · — (못 쟀어요) | X 측정 불가 |
| X를 확인하지 못했어요 · 받지 못했어요 | X 확인 실패 · X 수신 실패 |
| 서버에 닿지 못했어요 | 서버 연결 실패 |
| 서버가 사유를 보내지 않았어요 | 사유 미수신 |
| X가 없어요 · 아직 X가 없어요 | X 없음 |
| 몰라요 · 모름 · 값 없음 | 값 자리는 `N/A` · 이름표에 붙으면 `미상`(`수량 미상` · `시각 미상` · `데이터 출처 미상`) |
| 사유 미상 · 사유 없음 | 사유 미상 |
| 저장했어요 · 복사했어요 | 저장 완료 · 복사 완료 |
| 높아요 · 낮아요 · 평균보다 높아요 | 높음 · 낮음 · 평균 상회(하회) |
| 켜져 있어요 · 꺼져 있어요 | 사용 · 미사용 |
| 아직이에요 · 끝까지 갔어요 | 대기 · 완료 |
| 다시 시도 · 다시 계산하기 · 계산하기 | 재시도 · 재계산 · 계산 |
| 자세히 · 지우기 · 풀기 | 상세 · 삭제 · 해제 |
| ~할 수 있어요 | ~할 수 있습니다 (라벨이면 `~ 가능`) |
| ~해 주세요 | ~하십시오 |

- ★미상 ≠ 0★ 은 그대로다. `N/A` 옆에는 사유를 적는다(`N/A · 재무 미적재`). 0 이나 빈칸으로 그리지 않는다.
- 실패와 "값이 없음"을 섞지 않는 것도 그대로다 — `조회 실패`(서버에 못 닿음)와 `데이터 없음`(닿았는데 없음)은 다른 말이다.

## 4. 답 문장의 틀

화면 맨 위의 한 줄은 서버 필드를 틀에 끼운 것이다(ADR 003 §2.6 — 화면이 판단을 만들지 않는다). 틀은 개조식으로 쓴다.

- 기업: `현재가 {P}원 · 내재가치(추정) {V}원 · 괴리율 {±g}%` + 판정 칩. 내재가치가 없으면 `내재가치 산출 불가` + 사유(0% 를 지어내지 않는다).
- 성과: `총수익률 {r}% · CAGR {c}% · MDD {m}% · 샤프지수 {s}`.
- 판단 필드가 없으면 잰 값만 적는다(`시장 스트레스 52/100`).
