# 회사 질문지 · 견적 요청 목록 — PB 트레이더 도구 0단계 (2026-11-14)

> **상태: 질문 목록. 답은 전부 비어 있다(미상).** [로드맵](2026-11-14-pb-trader-tool-roadmap.md) §1 의 다섯 질문을 물을 수 있는 모양으로 풀었다.
> 답이 오면 '답 · 날짜 · 근거 문서' 칸을 채운다 — ★들은 말을 옮길 때는 누가·언제 말했는지 적고, 문서 근거가 없으면 '구두'라고 적는다★(추측으로 채우지 않는다).
> 소속 증권사의 API 질문 여섯은 [11-08 메모](2026-11-08-kyobo-pb-desktop-notes.md) §2 에 이미 있다 — 여기서는 그 뒤에 생긴 질문(선물옵션 · 해외 · 고객 제공 · 성과급)을 더한다.

## 순서 — 무엇부터 묻나

1. **성과급 규정(D)** — 온라인 계좌 수익이 실적으로 잡히지 않으면 수지 식이 성립하지 않는다. 가장 싸게 알 수 있고 가장 크게 가른다.
2. **API(A)** — 없으면 도구의 모양이 바뀐다(주문 연결 → 설계·검증·일지).
3. **준법·정보보호(B · C)** — 고객에게 내놓을 수 있는지.
4. **외부 견적(E)** — 위 셋의 답에 따라 필요한 것만.

## D. 성과급 규정 — 수지 식의 입력

| # | 질문 | 답 | 날짜 | 근거 |
|---|---|---|---|---|
| D1 | 온라인·비대면(HTS · MTS · API) 주문의 수수료가 관리 PB 의 실적으로 잡히나. 인정률은 | | | |
| D2 | 협의수수료 계좌의 수익은 어떻게 잡히나 | | | |
| D3 | 상품별 인정 — 국내 주식 · 해외 주식 · 국내 선물옵션 · 해외선물옵션 · 신용이자 | | | |
| D4 | BEP 와 지급률(구간별) | | | |
| D5 | 관리 계좌로 등록되는 조건 · 등록 뒤 유지 조건 | | | |
| D6 | 규정 개편 예정이 있나(업계에서 비관리계좌 몫을 조정하는 움직임이 보도됐다) | | | |

채워지면 로드맵 §3 의 식에 넣어 다시 계산한다: `월 성과급 = max(0, Σ 고객 수수료 수익 × 실적 인정률 − BEP) × 지급률`.

## 이 문서가 하지 않는 것

- 답을 추정하지 않는다. 빈 칸은 미상이다.
- 질문의 순서는 권고다 — 물어볼 수 있는 것부터 물어도 된다.
- 회사 내부 문서를 이 저장소에 옮겨 적지 않는다(근거 칸에는 문서 이름·날짜만 적는다).
