## 0. 요청과 전제

요청(2026-11-14): "플랫폼에 필요한 모든 금융 데이터를 구해 적재하려면 어떤 서비스를 써야 하나 · 수지타산에 맞으려면 얼마를 벌어야 하나 · 헤비 트레이더·단타 트레이더를 위한 전략 설계 기능도 넣고 싶다 · 장기적이고 완성도 높은 계획."

답받은 전제 넷:

| 물음 | 답 |
|---|---|
| 누가 돈을 내거나 버는가 | **증권사 PB 로서 전업·헤비 트레이더를 고객으로 만들기 위해, 그들의 투자에 도움이 되는 도구를 만들어 제공한다.** 비공개로 시작해 검증 뒤 제공 |
| 시장 | 한국 주식·ETF + 미국 주식 + 선물·옵션 전부("PB 에게 가장 수익성 높은 상품은 파생상품") |
| 단타 깊이 | 스윙(일봉 신호 + 분봉 체결) · 분봉 인트라데이 · 틱/호가 스캘핑 전부 |

- 가장 큰 미상은 데이터 값이 아니라 **소속 증권사의 API 형태와 회사 승인**이다(11-08 메모 — 교보증권 API 형태 미상).
- "전부 한다"는 기존 결정 넷과 부딪힌다 → §6 의 결정 기록을 먼저 쓴다.

### 1-A. 받은 답과 조사 (2026-11-14)

| 항목 | 내용 | 등급 |
|---|---|---|
| 수익 구조 | "고객의 주 관리자로 입력되면 PB 로서 브로커리지 수익을 얻는다" | 사용자 진술(구두). 인정률 · BEP · 지급률 수치는 미상 |
| 교보증권 API | 홈페이지에 '오픈API 서비스소개 · 사용신청' 메뉴가 있다는 것까지만 보였다. 다른 증권사와 달리 공개 개발자 포털·문서·사용 후기가 검색에 잡히지 않는다 | ★형태 미상★ — 이 환경이 그 사이트를 막아 본문을 읽지 못했다 |
| 전망 | "어차피 몇 년 뒤에는 다 될 것" — 2025~2026 에 한국투자 · 키움 · KB · 토스 · 메리츠가 개인용 API 를 잇달아 열었다(보도) | 흐름은 관측 · 교보증권의 시점은 미상 |
| 준법·정보보호 | "전략을 세우는 게 아니라 도구를 제공하는 것" | 판단은 아래 |

**'도구 제공'에 대한 판단**([경계 문서](../specs/2026-11-14-tool-provision-boundary.md) §2): 고객이 종목·조건·수량·시점을 직접 정하고 도구는 계산·실행만 하면 자문·일임이 아니다(금융위 법령해석 요약).
그것만으로 닫히지 않는 것이 셋이다 — ① 도구가 종목을 고르거나 판단이 담긴 설정값을 실어 주면 선을 넘는다 ② 증권사 직원이 고객에게 주는 도구는 자문 여부와 별개로 회사 절차 대상이다(국내 선례의 주체는 모두 증권사)
③ 정보보호는 구조로 푼다(고객 정보가 PB 쪽 서버에 오지 않게). 그래서 '도구 제공'을 ★제품 구조로 사실이 되게★ 만들고, 끝 그림은 회사가 채택해 회사 이름으로 내는 것(예스트레이더형)으로 둔다.

### ★설계 원칙 하나★ — 고객이 오래 살아남게 한다

이 도구가 고객의 **회전을 늘리는 장치**로 설계되면 과당매매·부당권유 문제이고, 고객이 손실로 떠나면 PB 실적도 끝난다.
PB 의 수익은 `거래대금 × 수수료율 × 인정률 × 고객이 남아 있는 기간`이다. 그래서 도구의 값은 마지막 항에 둔다:

- 비용 · 증거금 · 손실 한도를 전략보다 **먼저** 보여 준다.
- 비용 차감 후에도 남는 규칙만 통과시킨다(관문). 합성 백테스트는 수익의 증거가 아니다.
- 템플릿은 **예시 규칙**이지 추천이 아니다. 종목을 골라 주지 않는다.

이것은 이 저장소의 정체성("증거 관문을 판정한다" — CLAUDE.md §1)과 같은 방향이다.

## 3. 수지타산 — PB 기준의 식

`월 성과급 = max(0, Σ 고객 수수료 수익 × 실적 인정률 − BEP) × 지급률`. 도구가 맞으려면 `늘어난 성과급 ≥ 월 도구 비용`.

| 항목 | 값 | 등급 |
|---|---|---|
| 비공개 단계 월 도구 비용 | 50~100만 원(서버·DB·백업 10~40 + 미국 개인 요금제 + 해외선물 시세) | ★가정★ |
| 지급률 | 회사마다 다르다(삼성증권 사례: BEP 초과분의 최대 60% — 2023 보도) | 보도 · 소속사 미확인 |
| 예시 | 지급률 40% · 온라인 협의수수료 0.01% · 전액 인정 · 이미 BEP 를 넘은 상태 → 월 추가 수수료 수익 125~250만 원 = **월 약정 125~250억 원** | ★전부 가정★ — 식에 소속사 숫자를 넣어야 한다 |

- 헤비 트레이더 몇 명이면 닿는 규모지만 **인정률이 0 이면 0 이다**. 그래서 성과급 규정 확인이 데이터 견적보다 먼저다.
- 실제로 가장 큰 비용은 만드는 사람의 시간이다. 고객 제공 단계의 계약·인프라 비용은 개인이 아니라 회사 예산으로 가는 것이 정상 경로다(사내 도입).
- 고객 자신의 손익분기도 도구가 보여 줘야 한다: 2026년 주식 매도 거래세 0.20%(2차 자료) + 수수료 + 스프레드 → 왕복 0.25~0.35% 이상(추정).

참고(전제가 '구독 서비스'였다면): `손익분기 유료 가입자 = 월 고정비 ÷ (가입자당 월 매출 × 0.9)`. 종가 기반 서비스는 인건비 포함 월 800~2,000만 원 · 월 2.9만 원 구독이면 310~770명(전부 가정).
이 길은 고르지 않았다 — 시세 표출 계약·업권 등록이 개발보다 먼저 온다.

| **4 국내 선물 → 옵션** | 3~5개월 | 만기·롤오버·증거금 모델 · 옵션 체인·IV·그릭스 · 스프레드·헤지 구조 · 증거금 기준 손실 한도 · 파생 백테스트 | 증거금 부족·만기를 시뮬레이터가 재현한다 |
| **5 증권사 중립 설계 → 소속사 연결** | 설계는 2단계와 함께 · 연결은 소속사 API 가 열릴 때 | ★중립 설계를 먼저★: KIS 응답 칸을 증권사와 무관한 모양으로 · 계좌 저장에 증권사 칸(본인 검증은 한국투자 API). 소속사 API 가 열리면 어댑터와 그 mock · 오류 코드표(없는 코드는 미상). ★그때까지 소속사 고객에게는 주문은 HTS·MTS, 도구는 설계·검증·일지·관제★ + 체결 내역 가져오기 | 중립 모양으로 바꾼 뒤에도 기존 시험이 그대로 통과한다 → (열린 뒤) 소속사 모의 서버에서 주문 왕복을 관측한다 |
| **6 미국 주식 → 해외선물·미국 옵션** | 3~6개월 | 권리가 분명한 원천 · 환율·거래시간·세금 · 거래소별 시세료 | 원천마다 권리 대장에 근거가 있다 |
| **7 틱·호가(스캘핑)** | 3~6개월 | 소수 종목 관찰 → 저장 엔진 재검토 → 호가 기반 체결 모델 | 분봉 모델과의 차이를 실측으로 보인다 |
| **8 고객 제공** | 회사 승인 뒤 | ★끝 그림은 회사 채택(제휴형)★ — 회사가 준법 심의 · 시세 계약 · 고객 관계를 갖는다. 고객용 표면은 [경계 문서](../specs/2026-11-14-tool-provision-boundary.md) §3 의 조건(C1~C8)으로: 종목·조건은 고객이 정한다 · AI 보조·점수 순위 꺼짐 · 고객 본인 인증·본인 실행 · 고객 정보는 고객 쪽 | 승인·계약 기록이 선언돼 있다(그 전에는 관문이 닫혀 있다) · 조건마다 시험이 있다 |

- **첫 6개월 권고: 0 → 1 → 2.** 5단계는 회사 답이 오는 대로 병행한다. 4·6·7 은 2·3 의 시뮬레이터·실행기를 재사용하므로 그 뒤가 싸다.
- **그만둘 기준**: 회사가 고객 제공을 불허하면 8 은 닫고 본인 검증 도구로 남긴다 · 소속사 API 가 없으면 5 를 '체결 내역 가져오기'로 바꾼다 ·
  2단계에서 비용 반영 뒤 남는 규칙이 하나도 없으면 그 사실이 결과다(더 복잡한 모델로 덮지 않는다).

## 7. 지킬 것 · 하지 않는 것

- 순서: 데이터 무결성 → 시점 정합 → 비용 → 표본외 → 모의 → 실계좌. 건너뛴 관문은 통과한 관문이 아니다.
- 실거래 6중 안전장치 우회 금지 · 기본 `dry_run` · HTS 화면 조작(매크로)은 하지 않는다.
- 기존 백테스트 엔진 · `ValuationScreener` · 스크리너 3-레이어 · `constrained_opt.py` 는 고치지 않는다(새 시뮬레이터는 옆에 둔다).
- 회사 승인 전에는 고객 정보·고객 계좌를 이 도구에 넣지 않는다.
- 권리가 불분명한 원천을 고객 제공 경로에 쓰지 않는다.

## 8. 이 문서가 주장하지 않는 것 · 미확인

- 이 로드맵은 ★순서와 전제★다. 어느 전략이 수익을 낸다는 주장이 아니다 — 답하는 질문은 "무엇을 어떤 순서로 확인할 것인가"다.
- 기간·비용·약정 규모는 가정이다. 소속사 숫자와 견적이 오면 §3 을 다시 계산한다.
- 미확인: 코스콤·KRX 요금 · 소속 증권사 API 의 형태(11-14 조사에서도 읽지 못했다)와 성과급 규정의 수치 · 금소법 현행 조문 · 투자자문·일임 등록 요건 수치 · KIS 웹소켓 등록 한도 ·
  공공데이터 원천의 상업 이용 범위 · 경쟁 서비스 요금 · 파생 수수료율 · 개인 파생 거래자의 손실 통계(원문을 찾지 못했다).
- 규제 해석은 법률 자문이 아니다. 조사에서 읽은 것은 조문 요약·보도·법령해석 한 건이다 — 적용 전에 준법감시와 법률 자문의 답이 필요하다.
