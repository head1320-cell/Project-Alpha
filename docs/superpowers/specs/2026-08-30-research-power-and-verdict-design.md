# 검정력 산출 + 판정 어휘 5분류 — 설계 (A1·A2, 2026-08-30)

> 상위 감사: [`docs/specs/2026-08-29-macro-research-architecture-audit.md`](../../specs/2026-08-29-macro-research-architecture-audit.md)
> 이 문서는 **연구 실행이 아니라 인프라 설계**다 — 사전등록이 필요한 판정을
> 내지 않는다. 이 도구로 내리는 판정(A3 의 M1~M5 재판정)은 별도로 사전등록한다.

## 0. 왜

감사가 낸 최상위 통계 부채 두 개:

| 부채 | 증거 |
|---|---|
| 어떤 관문도 **MDE·검정력을 보고하지 않는다** | M1~M5 리포트에 필드 없음 |
| `p>0.05` 와 "효과 없음" 을 가르는 **어휘가 없다** | `verdict.passed` 불리언뿐 |

M1~M5 가 정확히 이 구멍에 빠졌다. 양성 통제(수익이 `_PROF[regime]` 에서 생성되는
심어진 패널)에서 심은 효과 1× 의 검출률이 **40%** 였는데 — 즉 관문이 애초에 찾을
힘이 없었는데 — 리포트에는 "불통과" 만 남았다. ★관문이 고장난 것이 아니라 정확히
검정력이 모자랐다★ 는 사실을 담을 자리가 없었다.

## 1. A1 — `src/engine/research_power.py`

★의존성을 뒤집는다★ 이 모듈은 하네스를 import 하지 않고 `power_curve` 가
**시행 함수를 주입**받는다. 그래서 규칙 자체를 합성 시행으로 정확히 검사할 수
있고, 하네스가 바뀌어도 깨지지 않는다.

| 함수 | 계약 |
|---|---|
| `mean_pairwise_correlation(m)` | 열 간 **비대각** 상관의 평균. 1열이면 `None`(짝이 없으면 상관도 없다) |
| `design_effect(N, ρ̄)` | `1 + (N−1)ρ̄`, ★1 아래로 자른다★ |
| `effective_n(T, N, ρ̄)` | `N·T / deff`. ρ̄ 미상이면 `None` |
| `detection_rate(outcomes)` | ★미상 ≠ 실패★ — `None` 은 분모에서 뺀다. 전부 미상이면 `rate=None` + 사유 |
| `wilson_interval(k, n)` | 0%·100% 에서 폭 0 을 내는 Wald 대신 Wilson |
| `power_curve(trial, scales, seeds)` | 척도×시드 격자. ★예외를 삼키지 않는다★ |
| `mde_from_curve(curve)` | 목표에 처음 도달하는 **시험 척도**. 미도달이면 `None` + 사유 |
| `power_report(...)` | `mde`·`power`·`n_eff` 를 한 블록으로 |

### ★"492 자산-월" 은 독립 표본이 아니다★

실측에서 자산간 상관이 자산 수와 **무관하게** ~0.58 로 고정이었다. 국면은
공통인자라 유효 관측이 월당 ~1개이지 N 개가 아니다.

```
6자산 · 84개월 · ρ̄=0.58  →  deff = 3.9  →  n_eff ≈ 129  (504 가 아니다)
```

8배 자산(6→50)이 유효 표본을 1.5배도 못 산다. 반면 개월 수는 그대로 비례한다.
★자산 말고 개월★ 이라는 감사 §3 의 결론이 여기서 수치가 된다.

### ★격자 사이를 보간하지 않는다★

1× 에서 0%, 2× 에서 100% 라면 격자가 말해 주는 것은 "1× 로는 못 찾고 2× 면
찾는다" 뿐이다. 선형 보간해 "MDE = 1.8" 이라고 적으면 **시험하지 않은 척도의
검정력을 주장**하는 것이다. MDE 는 목표에 도달한 **가장 작은 시험 척도**로 적고
참값이 든 구간을 `bracket` 으로 함께 낸다. 최소 척도에서 이미 도달했으면
`at_search_floor` — 참 MDE 는 더 작을 수 있다는 뜻이다.

실측 곡선은 40/80/0/80/60 처럼 **비단조**였다. 매끈한 척하지 않고 `monotone` 과
교차 횟수를 함께 적고 **첫 교차**를 쓴다. 5시드의 ±20%p 노이즈는 Wilson 구간으로
드러낸다.

## 2. A2 — `src/engine/research_verdict.py`

| 판정 | 뜻 |
|---|---|
| `positive` | 널 밖이고 탐색 보정 후에도 유의하다 |
| `inconclusive` | 두 관문이 엇갈린다 — ★M1~M5 의 실제 형태★ |
| `underpowered` | 못 넘었는데 **검정력이 모자랐다** |
| `evidence_of_no_effect` | 못 넘었고 **찾을 힘은 충분했다** |
| `no_evidence` | 관문을 못 돌렸거나 검정력을 모른다 |

### ★만다트 §4 의 계약★

`p > 0.05` 만으로는 결코 `evidence_of_no_effect` 가 되지 않는다. 반드시
**입증된 검정력**이 있어야 한다. 짝 테스트가 그것을 건다 — `power` 가
`None`·0.10·0.40·0.79 중 무엇이어도 `evidence_of_no_effect` 는 나오지 않고,
0.95 에서는 나온다(언제나 `underpowered` 를 내는 구현 배제).

### 판정 순서가 계약이다

1. 두 관문 다 통과 → `positive`. ★검정력은 **못 찾은 것**을 읽을 때 필요하다★ —
   찾았으면 찾은 것이므로 `positive` 는 검정력 없이도 선다.
2. 어느 하나라도 미상 → `no_evidence`. ★미상 ≠ 아니오★
3. 정확히 하나만 통과 → `inconclusive`
4. 둘 다 실패 · 검정력 미상 → `no_evidence`.
   ★모르는 검정력은 '낮은 검정력' 이 아니다★ — 둘은 다른 진술이다.
5. 둘 다 실패 · `power ≥ 목표` → `evidence_of_no_effect`, 아니면 `underpowered`.

`target_power = 0.80` 은 ★관례이지 측정치가 아니다★ — 리포트에 함께 싣고, 바꾸면
판정이 바뀐다는 것을 테스트가 보인다(임계 관례 테스트와 같은 규율).

### `require_power_fields(report)`

★리포트에 검정력이 없으면 그 리포트는 불완전하다★ `mde`·`power`·`n_eff` 키가
있어야 하고, 값이 `None` 인 것은 괜찮되 **사유와 함께**여야 한다. 사유 없는
`None` 과 빈 문자열 사유는 침묵 폴백이다.

## 3. 기존 코드 연결

`scripts/regime_control.decide_verdict` 는 **`passed` 의 규칙을 한 자도 바꾸지
않고**(`널 밖 and SPA 유의`) `verdict`·`mde`·`power`·`n_eff`·`reasons` 를
덧붙인다. `power_block` 을 안 주면 세 필드가 **사유와 함께 미상**으로 실린다 —
빈칸으로 두지 않는다. `null_stats` 를 단일 출처로 삼은 것과 같은 패턴이다.

## 4. 하지 않은 것

- **A3(M1~M5 재판정)** — 이 도구로 실제 검정력 곡선을 돌려 `underpowered` 라벨을
  붙이는 것은 다음 단계다. 사전등록 원문(`13ba50a`)은 보존한다.
- **양성 통제 어댑터** — `t3_transmission` 프로파일에 척도를 곱하는 얇은 어댑터는
  A3 에서 만든다. A1 은 주입 인터페이스만 정의한다.
- **증거 등급 상향·예측 스킬 주장** — 이 커밋은 **아무 투자 주장도 하지 않는다.**
  검정력 계산은 ①~④ 어느 질문에도 답하지 않고, "어떤 질문에 답할 수 있었는가" 만
  답한다.
