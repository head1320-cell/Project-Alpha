## 5. 찍는 스크립트 — `frontend/scripts/readme-shots/` (남김 · CI·E2E 밖)

- `shoot.mjs` + `README.md`. 쓰는 법: `cd frontend && npx next build && node scripts/readme-shots/shoot.mjs [--only 이름…]`.
- 미리 `next build` 가 필요하다. ★제 포트(기본 `SHOTS_WEB_PORT=3900` · `SHOTS_API_PORT=8900`)가 비어 있어야 하고, 다른 프로세스는 끄지 않는다★(진단 도구 `run.sh` 와 같은 규율).
- 새 임시 SQLite 파일로 백엔드(`KIS_USE_MOCK=1`)와 프론트(`next start`)를 제가 띄우고, 끝나면(실패해도) 제가 띄운 것만 끈다.
- 준비: 로그인 → 지어낸 고객 셋 → 캔버스 기본 사슬 계산 → 백테스트는 기본 설정으로 실제 실행(RM 과 같음).
  내 계좌는 금고 키가 없어 `my-account.spec.ts` 와 같은 응답을 정해 찍는다(RM 과 같음 · 스크립트 주석에 밝힘).
- AI: 첫 AI 그림 전에 `POST /api/v1/assist/canvas/suggest` 로 한 번 묻는다. ★`available:false` 면 AI 그림을 하나도 쓰지 않고 사유와 함께 0 아닌 값으로 끝난다★ —
  허전한 그림을 조용히 남기지 않는다. AI 아닌 그림은 그 전에 쓴다(`--only` 로 AI 아닌 것만 다시 찍을 수 있다).
- 브라우저 경로는 `playwright.config.ts` 와 같은 규칙(`PW_CHROMIUM_PATH` 또는 샌드박스 경로). 끝에 쓴 그림 이름과 크기를 출력한다.
