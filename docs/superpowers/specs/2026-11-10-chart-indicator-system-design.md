## 3. 설계

### A. 표식 규격 한 곳 — `frontend/src/shared/ui/chart/chartSpec.ts`

```ts
export const MARK = { line: 2, quiet: 1.5, dotR: 4, ring: 2, wash: 0.1, barMax: 24, barR: 4 } as const;
export const AXIS_TICK = { fontSize: 12, fill: "var(--tx-sub)" } as const;
export const ringDot = (color: string) => ({ r: MARK.dotR, fill: color, stroke: "var(--tx-surface)", strokeWidth: MARK.ring });
```

- 선 2px. 뒤로 물리는 선은 1.5px + 흐림(굵기로 강조하지 않는다).
- 점 r4 + 표면색 고리 2px(선과 겹치는 자리에서도 읽힌다).
- 면은 계열 색 10% 단색(그라데이션 `<defs>` 삭제).
- 격자는 실선 1px. **주석선**(평균 · 손익분기 · 내재가치)의 점선은 뜻이 있어 그대로 둔다.
- 막대는 24px 이하 · 자료 끝만 4px 둥글림.
- 축 글자 12px 하나.
- 손그림(`MiniPlots` · `.pg-plot-*`)도 같은 값. 프론티어 구름 점은 계열 표식이 아니라 배경 점이라 그대로.
- 이 파일은 recharts 를 import 하지 않는다(경계 규칙).

### B. 형태 고침 둘

1. **`StoryChart` — 이중 축 → 위아래 두 칸.** 단위가 다른 두 측정(원 · %)을 한 그림의 두 축에 올리면 두 축의 눈금 비율이 그림의 "관계"를 만든다.
   위 칸 = 매출 막대, 아래 칸 = 영업이익률(실선+점) · 순이익률(점선). 두 칸은 같은 기간 축(`scale="band"`)과 같은 왼쪽 축 폭을 써서
   막대 가운데와 점이 한 줄에 선다. 오른쪽 축은 없다.
2. **`PriceValueChart` — 겹친 띠 → 오른쪽 "가치 범위 막대" 칸.** 주가 선은 왼쪽 구역, 모형별 범위(lo~hi)는 오른쪽 구역에 겹치지 않는 가는 세로 막대로.
   **y 축은 하나**라 주가와 범위를 같은 눈금으로 견준다. 마지막 종가에서 범위 칸을 가로지르는 가는 선을 그어 "지금 주가가 각 범위 안인가"를 바로 읽게 한다.
   x 는 그림 px 단위의 숫자 축(잰 폭)이라 막대 폭이 화면 폭과 무관하게 규격대로다. 그림 밖 규칙(4배↑ · 0.15배↓)과 값은 그대로.

### C. 값은 늘 읽힌다 — 읽는 줄을 남은 차트에 (ADR 004 §2.4 마무리)

- `ChartReadout.tsx` 의 `useReadout` · `ReadoutFrame` · `idxFromChartEvent` 그대로. 보탬 하나: `ReadoutFrame` 의 `table?: boolean`(기본 true) —
  절에 이미 표가 있으면 표 쌍둥이를 겹치지 않는다.
- 대상(`data-chart`): `yield-curve` · `axis-stack-growth` · `axis-stack-inflation` · `studio-factor` · `studio-curve` · `studio-tp` · `price-1y` ·
  `price-value` · `kpi-revenue` · `kpi-op` · `kpi-ni` · `story` · `cva-exposure`.
- 선·면은 십자선 + 고리 점, 막대는 고른 기간 뒤의 옅은 띠. 처음 자리는 마지막 점. 글자는 툴팁이 쓰던 서식 함수 그대로(새 셈 0).
- 다중 계열의 읽는 줄은 선 표식(`.cr-key`)으로 범례 구실도 한다 → 대비 WARN 3색의 의무가 채워진다.
- 하지 않는 둘: `RegimeScatter`(점 하나 · 값이 글자로 있다) · `Payoff`(화면이 그린 61 표본 · 손익분기와 최대 손실이 글로 있다).
- 끝나면 `<Tooltip>` 은 0 이고 린트가 다시 들어오지 못하게 막는다. `TIP_STYLE` · `TX_TIP_STYLE` 은 삭제.

### D. 지표

1. **스파크라인 하나** — `plotGeo.ts::sparkPoints` + `shared/ui/plot/Spark.tsx`. 1.5px · 둥근 이음 · 늘어나지 않는 선 · 끝 점(지금) · null/NaN 건너뜀 ·
   값이 둘 미만이면 빈 자리(선을 지어내지 않는다). 다섯 자리는 제 클래스·속성·색 규칙을 그대로 둔다.
2. **큰 숫자는 비례폭 숫자** — 홀로 선 값(≥20px)에서 `tabular-nums` 를 걷는다. 고정폭 숫자는 세로로 줄을 맞춰야 하는 곳(표 · 축)에만.
3. 게이지 · 확률 막대 · z 막대는 형태 그대로.

### E. 옆줄 테두리

알림·인용 상자의 `border-left ≥ 2px` → 전체 1px 테두리 + 옅은 바탕(이미 있는 토큰). 멀리 보기 줌의 노드 단계 색 띠(글자가 숨는 줌의 유일한 부호)와
0폭 위치 표식선은 그대로.

## 4. 시험

- 새 `e2e/chart-marks.spec.ts` — 차트마다 격자 실선 · 선 굵기 ∈ {2, 1.5} · 점 r ≥ 4 + 고리 · 면이 그라데이션 아님 · 막대 ≤ 24px.
- 읽는 줄 — `macro-cards` · `macro-studios` · `insights` · `derivatives` 스펙: 툴팁 래퍼 0 · 마지막 값 = 같은 실행의 서버 값 서식 · ← 로 앞 점 · 표 행 수 = 서버 점 수.
- 형태 — `insights`: 스토리 칸마다 y 축 1 · 막대 가운데 x ≈ 점 x · 범위 막대끼리 안 겹침 · 폭 ≤ 24 · 주가 끝 점 오른쪽.
- 새 `e2e/figures.spec.ts` — 홀로 선 숫자 ≥20px 는 `tabular-nums` 가 아니다 + 짝(표 숫자 칸은 `tabular-nums` 다) · 스파크라인 굵기·끝 점.
- 옆줄 — 그 상태에 닿는 스펙에 `borderLeftWidth ≤ 1` + 짝 `borderTopWidth ≥ 1`.
- 변이: 점선 되살림 · 굵기 2.5 · 점 r3 · 읽는 줄 자리 0 고정 · 표 솎기 · 오른쪽 축 되살림 · 막대를 전폭 띠로 · `scale=band` 제거 · tabular 되살림 · 끝 점 삭제 · 차트 파일에 `Tooltip` import.
- 골든: 색·테두리가 바뀌는 라우트만 `light-styles.json` 을 다시 얼리고 `golden-diff` 출력을 커밋 메시지에 싣는다.

## 6. 실물 대 설계 (구현 뒤 · 2026-11-10)

설계대로 되지 않았거나 만들면서 정한 것 — 숨기지 않고 적는다.

1. **고리 점의 반지름.** 설계는 "r4 + 고리 2px"였는데 SVG 선은 반지름 안팎으로 반씩 걸쳐 보이는 색 점이 r3 으로 줄었다(스크린샷에서 작아 보였다).
   `ringDot` · `pickDot` 의 r 은 `dotR + ring / 2`(= 5) — 보이는 색 점이 r4 다. 손그림 `.pg-curve-pt` 도 같다.
2. **범례를 뺀 곳 둘.** 축 쌓기와 스튜디오 곡선은 읽는 줄의 선 표식이 이름·색·값을 다 적는다 → 따로 있던 범례(`.mc-legend`)를 뺐다(같은 이름을 두 번 적지 않는다).
3. **금리곡선 글자.** 예전 툴팁은 서버 값을 그대로(3.9095%) 적었다. 읽는 줄은 소수 둘째 자리(캔버스 수익률곡선과 같게). 음수는 빼기표(−).
4. **이야기 그림 아래 칸의 가로 맞춤.** 설계는 두 칸 모두 `scale="band"`였다. 그러면 점은 띠 가운데로 가지만 기간 글자가 띠 왼쪽 끝에 남는다(recharts 는
   막대가 있는 그림에서만 글자를 가운데 둔다). 막힌 길 둘 — ⑴ 값 없는 막대를 넣으면 막대 요소가 8개 더 생겨 "막대 = 기간 수" 계약이 깨진다(기존 시험이 잡았다)
   ⑵ `hide` 막대는 막대로 쳐 주지 않는다. 지금은 잰 폭으로 양 끝을 반 칸씩 띄운다(`padding`).
5. **★주가의 읽는 줄은 서버 종가★ — 설계에 없던 발견.** `entities/company/data.ts::mapPrices` 는 과거 종가 전부에 (헤더 현재가 ÷ 마지막 종가) 배율을 곱해
   그린다. 예전 툴팁은 그 옮긴 값을 "종가"라고 적었다. 늘 보이는 줄과 표에는 서버 `date` · `close` 를 그대로 싣고, 그림 높이와 0.5% 넘게 다르면 한 줄로 말한다.
   ★배율 자체(그림 높이)는 고치지 않았다★ — 화면이 하던 기존 셈이고 별건이다(작업 카드 제안은 도구 시간 초과로 올리지 못했다 · HISTORY 에 적었다).
6. **값이 한 점인 범위.** 그레이엄 넘버처럼 lo = hi 인 범위는 예전에도 보이지 않았다. 막대 폭만큼의 높이를 준다(둥근 점으로 보인다 · 값은 범례에 그대로).
7. **표 쌍둥이를 끈 곳은 막대 셋뿐.** 이야기 그림은 제 표 쌍둥이를 갖는다 — 절의 재무 표에는 연간 영업이익률·순이익률이 없다.
8. **파생 그림 상자의 `role="img"`.** 읽는 줄이 그 안에 있으면 보조 기술이 읽지 못한다 → 걷고, 이름은 읽는 줄 틀이 갖는다.
9. **스파크라인 끝 점에는 고리가 없다.** 그 점을 가로지르는 선이 없어 고리가 필요 없고, 카드마다 바탕색이 달라 고리 색을 하나로 정할 수 없다.
   값이 모두 같으면 선을 가운데에 긋는다(예전엔 바닥 — "가장 낮다"로 읽혔다).
10. **큰 숫자의 범위.** 설계는 9 계열 + 5였고 화면에서 잰 것은 22 선택자다(매크로 9 · 기업 5 · 위험 도구 1 · 파생 2 · 백테스트·캔버스 5). 숫자가 든 제목
    (`.mc-strat-title`)도 들어갔다. 선택자 목록은 `globals.css` 끝의 한 블록에 있다.
11. **옆줄 테두리.** 설계 목록에 `.mx-bias` · `.login-error` 를 더했다. `.pg-claim` 은 그 상태에 닿는 스펙이 없어 CSS 만 고쳤다(단언 없음).
    쓰는 곳이 없는 `.bt2 …` · `.pg-simple-result--blocked/failed` 규칙은 그대로 뒀다.
12. **커밋 나눔.** E(옆줄 테두리)는 ⑦ 이 아니라 ⑥ 에 D(지표)와 함께 들어갔다 — 둘 다 `globals.css` 를 고쳐 파일로 나눌 수 없었다. ⑦ 은 기록이다.
    커밋 ③ 의 제목은 "다섯"이라고 적었는데 그림은 여섯이다(금리곡선 1 · 축 쌓기 2 · 스튜디오 3).
13. **변이.** 스물(② 6 · ③ 3 · ④ 8 · ⑤ 2 · ⑥ 2 — 전부 죽었다) + 옆줄 단언 6건은 CSS 를 고치기 전 빨강을 먼저 봤다. 한 번에 여럿을 넣으면 시험이 첫 단언에서
    멈춰 뒤의 단언이 가려진다 → ④ 는 세 번에 나눠 돌렸다.
