## 1. 지금 상태 (감사, 읽기 전용)

**캔버스**(`frontend/src/widgets/portfolio-graph/`, `frontend/src/entities/portfolio-graph/`)
- `reactflow@11.11.4` 를 쓴다.
  - 노드 종류는 셋(`pgNode`·`pgGroup`·`pgBranch`), 선 종류는 하나(`pgWire` = `EvidenceEdge`)다.
  - `Background` 는 점 간격 22, `Controls` 는 단추 셋, `MiniMap` 은 기본 꺼짐이다.
- 노드는 카드 하나에 모든 내용을 그린다(`GraphNode.tsx`).
  - 소켓 이름은 마우스를 올리거나 가까이 확대해야 보인다.
  - 설정은 오른쪽 판(`SettingsPanel.tsx`)에서만 바꾼다.
- 선은 `getBezierPath` 로 그린다(`EvidenceEdge.tsx`).
  - 계보 모양: 실선 · 연습용 점선 · 시점 전용 눈금 · 막힘 끊김.
  - 선 요약(`briefs`)은 출력 포트마다 한 번만 그린다.
  - 선을 누르면 "선" 탭이 열린다(`WirePanel.tsx`: 무엇이 흐르나·어디서 어디로·역할·믿을 수 있나·끊으면).
  - 사이에 넣기가 있다.
- 연결 규칙은 `connectionProblem()`(`E/connect.ts`)이다: 같은 타입 · 한 입력에 한 선 · 순환 금지 · 사유 문장.
- 배치는 직접 짠 열 배치(`autoLayout`, `COL=230`)다. dagre·elk 는 없다. 크기 상수는 `E/size.ts` 에 있다.
- 추천은 서버 규칙이 낸다: `procedure.next` · `by_gate` · `fixes` → `applySuggestion`. 팔레트 머리의 "지금 이을 수 있어요"도 있다.
- 큰 파일: `PortfolioCanvas.tsx` 1,532줄 · `store.ts` 1,007줄.
- 캔버스 E2E 는 약 190개다. 그중 `react-flow__*` 선택자가 약 104곳이다.
- v11 전용 API 를 쓰는 곳은 적다:
  - `nodeInternals`·`positionAbsolute` (`toolbarPlace.ts`, `PortfolioCanvas.tsx:132-138,578`)
  - `getRectOfNodes`
  - `useStore` 의 연결 중 상태 (`GraphNode.tsx:69`)

**AI**
- 저장소의 LLM 호출은 전부 `src/services/narrative/claude_client.py` 를 거친다.
  - Anthropic SDK 를 쓴다. 시간 제한 60초 · 재시도 3 · 차단기 · 캐시 1시간 · 비용 집계가 있다.

## 2. 원칙 (기존 결정과의 관계)

1. **설명은 서버가 쓴다**(BJ·ADR-002).
   - 관계 문장·역할·요약은 서버의 사실로만 만든다.
   - AI 글도 서버가 만들고 서버가 검사한다. 화면은 그리기만 한다.
2. **값을 지어내지 않는다 · 설정값과 "최선"은 추천하지 않는다**(BM 기각 사항).
   - AI 는 빠진 단계·노드를 제안한다.
   - 말로 설계는 사용자가 말한 값만 매개변수에 넣는다. 그 값에는 출처 칩 "말씀에서"를 붙인다.
3. **침묵 폴백 금지**(CLAUDE.md §4).
   - 키 없음 · 차단기 열림 · 호출 한도 · 검사 탈락은 각각 사유와 함께 보인다.
   - 규칙 기반 대체(`procedure.next`)는 "규칙 추천" 라벨로만 보인다. 데모 글을 AI 글처럼 내지 않는다.
4. **금지 표현**(검증됨·입증됨·견고함·프로덕션 레디·투자 우위·더 나은 전략)은 AI 출력에도 서버에서 건다. 연습용 경고는 AI 글 위에도 그대로 둔다.
5. **키는 서버에만** 둔다(`NEXT_PUBLIC_*` 금지 · 로그·응답에 키 0).
6. **툴팁 금지**(ADR-001) · **CSS 클래스 = E2E 계약** · **커밋 전 PNG 허락** · **시각화는 없애지 않고 더 좋게 대체**.
7. **ComfyUI 를 그대로 베끼지 않는다.**
   - 어두운 회색 판·작은 고정폭 글은 가져오지 않는다.
   - 가져오는 것은 구조: 소켓 줄 · 노드 안 위젯 · 경유점 · 큐다.
   - 겉모습은 토스식 토큰(`--tx-*`·`--pg-*`) · Pretendard · 라이트/다크 짝이다.

## 3. 1부 · 캔버스

### CF0 · React Flow v12 이사 (보이는 변화 0)

- `reactflow@11` 을 `@xyflow/react` 로 바꾼다. 버전은 정확히 고정하고, 나온 지 2주 이상 된 것을 쓴다.
- 바꿀 곳:

  | v11 | v12 |

  | import 경로 | `@xyflow/react` |
  | `reactflow/dist/style.css` | `@xyflow/react/dist/style.css` |

  | `positionAbsolute` | `internals.positionAbsolute` |
  | `getRectOfNodes` | `getNodesBounds` |
  | 연결 중 상태 | `useConnection` |
  | `node.width/height` | `measured` |

- 먼저 확인할 것: v12 DOM 의 클래스가 `react-flow__node`·`react-flow__edge`·`react-flow__handle` 와 같은지.
  다르면 같은 커밋에서 스펙을 고친다.
- 증거:
  - 캔버스 E2E 전부와 전체 E2E 가 통과한다.
  - 라이트 골든 변화 0.
  - 캔버스 장면 전·후 픽셀 비교에서 흔들림 기준선 밖 차이가 0.
  - 첫 로드 JS 증감을 기록한다.

### CF1 · 노드 해부 — 확대 3단

**가까이**(확대 ≥ 1.05)는 새 `WorkNode`, ComfyUI 작업 노드다.

```
┌─ ③ 비중 계산 ───────────────────── ● ─┐   제목 줄: 단계 번호 · 쉬운 이름 · 상태 점 · 접기
│ ● 수익률   필수                  비중 ● │   소켓 줄: 입력 왼쪽 · 출력 오른쪽 · 이름 늘 보임
│ ○ 내 생각  선택              위험보고 ● │            필수 ● / 선택 ○ · 연결 수
│────────────────────────────────────────│
│ 방법   [평균-분산        ▾]              │   위젯 2~4개: 서버 x-ui 기본 필드(질문형 라벨)
│ 위험   ○────●────○  보통                │            설정 판과 같은 setParam · 되돌리기
│────────────────────────────────────────│
│ ▓▓▓▓▓▒▒▒░░  삼성 33% · 하이닉스 …       │   결과 미리보기: 기존 glance·도넛·헤드라인 숫자
│ [연습용] [가정 2]         0.4초 · 완료   │   상태 줄: 계보 칩 · 가정 n · 시간
└────────────────────────────────────────┘
```

**중간**: 제목 + 소켓 이름 + 헤드라인 숫자. **멀리**(< 0.55): 지금의 요약 카드.

- 노드 폭은 내용에 따라 정한다(v12 실측 크기). `E/size.ts` 상수 의존을 자동 정리·묶음 경계·도구줄 위치에서 걷는다.
- 위젯에 넣을 필드는 서버 카탈로그 `params_schema` 의 `x-ui.basic` 을 따른다(새 판단 0).
  - 넷이 넘으면 "설정 더 보기"로 오른쪽 판을 연다.
  - 위젯을 바꾸면 BT5 규칙대로 그 노드와 하류가 "예전 결과"가 된다.
- 오른쪽 판은 이야기 · 자세히 · 전문가 설정 · 선으로 둔다. 기본 설정은 노드 안으로 옮기고, 판의 기본 설정은 같은 컴포넌트를 재사용한다.
- 노드 접기: 제목 줄만 남기고 소켓은 제목 줄 양끝에 모은다(ComfyUI collapse).

### CF2 · 소켓·핸들

- 모양은 타입색에 필수(채운 원)·선택(빈 원)을 더한다. 받을 수 있는 입력이 여럿인 소켓(`portfolio_combine`)은 칸 모양이다.
- 끄는 동안 커스텀 연결선(`connectionLineComponent`)을 그린다.
  - 선은 타입색이다.
  - 받을 수 있는 소켓은 커진다(기존 `can`/`needs`/`off`).
  - 거부 사유는 커서 옆에 보이는 글 한 줄로 쓴다(`connectionProblem` 문장 그대로, 툴팁 아님).
- 선 끝 다시 꽂기(v12 reconnect): 같은 규칙으로 검사하고, 되돌리기는 한 번이다.
- 소켓을 두 번 누르면 그 타입으로 빠른 추가를 연다(기존 QuickAdd 의 source/target 경로).

### CF3 · 링크 = 노드와 노드의 관계

**서버: 관계 문장.** 새 `src/api/allocation_graph_relations.py` 는 순수 함수다.
- `/validate` 와 `/run` 응답에 `relations: {edge_id: {text, flows, role, required}}` 를 싣는다.
- 문장 틀은 정해져 있다(조사 문제를 피한 틀):
  `‘{보내는 노드}’의 {포트 쉬운 이름}({선 요약}) → ‘{받는 노드}’ {받는 포트 쉬운 이름} 자리. {받는 포트 role}`
- 선 요약이 없으면(계산 전) 괄호를 뺀다. `role` 이 없으면 둘째 문장을 뺀다.
- 금지 표현 검사와 순수성(AST) 검사를 받는다.

**화면**
1. **무엇이 흐르나**: 선 가운데 알약(타입 쉬운 이름 + 서버 요약). 가까이는 늘, 중간은 고른 선·올린 선만, 멀리는 색만 보인다.
2. **왜 필요한가**: 받는 소켓 옆에 역할 한 줄을 쓴다(가까이). 필수 입력 선은 굵게(3), 선택 입력 선은 가늘게(1.75).
3. **믿을 수 있나·살아 있나**:
   - 계보 모양은 유지한다.
   - 예전 결과인 선은 흐리게(투명도) 그린다.
   - 계산 중에는 선을 따라 점이 흐른다(감속 모션이면 멈춤).
   - 막힌 선은 끊김 + 회색이다.
4. **관계**: 선을 고르면 그 선 위에 관계 문장 판과 [끊기]·[사이에 넣기] 단추가 뜬다. "선" 탭 맨 위에도 관계 문장을 둔다.
5. **정리·조작**:
   - 경유점(ComfyUI reroute): 선 위를 두 번 누르면 점이 생기고, 점은 끌어 옮기고 두 번 누르면 지운다.
     문서 edges 의 `waypoints:[{x,y}]` 에 저장한다. 엔진 의미는 0이다. 서버가 모르는 칸은 무시하는지 pytest 로 고정한다.
   - 선 모양 전환(곡선/직각/직선): 전역 보기 설정, localStorage.

### CF4 · 배경·배치

- 격자 두 겹: 작은 칸 점(22) + 큰 칸 선(110). 라이트/다크 토큰이고, 스냅 격자와 맞춘다.
- 끌 때 정렬 안내선: 다른 노드의 가장자리·가운데와 맞으면 선이 보이고 붙는다.
- 여러 개를 고르면 정렬(왼·가운데·위)·간격 맞추기를 한다.
- 자동 정리를 실측 크기 기반 왼→오 열 배치로 바꾼다(기존 깊이 열 규칙 유지).
- 단계 레인 보기(도구줄 토글):
  - 배경에 6 띠(데이터→신호→생각→비중→확인→실행)와 레인 머리를 깐다.
  - [레인에 맞추기]를 누르면 노드를 자기 단계(카탈로그 `stage`) 띠로 옮긴다. 되돌리기는 한 번이다.
  - 레인 보기에서도 자유 이동은 막지 않는다.

### CF5 · 보조 컨트롤러

- 미니맵: 단계색 + 상태색(실패 빨강 테두리), 고른 노드 강조. 기본으로 켜고 접을 수 있다.
- 확대 단추 + 확대율 표시(누르면 100%) + 전체 보기.
- 실행 줄(ComfyUI 큐): 계산할 때 노드별 대기·진행·시간·실패를 한 줄 목록으로 보인다. 누르면 그 노드로 간다. 기존 진행 알약을 대체·확장한다.
- 선택 도구 상자: 여러 개를 고르면 정렬·묶기·갈래·견고성 비교. 기존 SelBar 를 확장한다.

### CF6 · AI 자리 (규칙으로 먼저 채움)

- 유령 노드: 반투명 노드 + 점선 추천 링크 + "추천" 칩 + [붙이기]·[닫기]. 처음에는 `procedure.next`·`by_gate` 로 채우고 라벨은 "규칙 추천"이다.
- "묻기" 칸(노드·선 판 아래)과 내러티브(이야기 탭) AI 절은 자리와 빈 상태만 만든다. 2부가 채운다.

  - 구조화 출력(tool use / JSON 스키마)을 쓴다.
  - 모델 id·가격표는 구현 때 claude-api 스킬로 확인한다. 기본은 환경 변수 `CLAUDE_MODEL` 이다.
- 경로 `POST /api/v1/allocation/graph/assist/{suggest,narrate,ask,draft,guide}`:
  - 로그인이 필요하다. 보호 목록·로그인 지도를 갱신한다.
  - 경로 이름에 `provider`·`subscribe` 류 금지어가 없다(`test_distribution_blocked`).
- **검사**(모두 서버):
  1. 노드 종류는 카탈로그에 있어야 한다.
  2. 연결은 `connectionProblem` + `validate` 를 통과해야 한다.
  3. 글 속 숫자는 근거 묶음에 있는 숫자만 쓴다. 아니면 탈락하고 사유를 남긴다.
  4. 금지 표현이 0이어야 한다.
  5. 연습용이면 경고가 남아야 한다.
  6. 설정값을 추천하지 않는다(suggest 출력 스키마에 params 칸이 없다).
- 탈락·키 없음·차단기·한도 초과: `{available:false, reason}` 과 규칙 대체를 함께 낸다. 화면은 "AI 답을 보여 줄 수 없어요: {사유}"를 보인다.
- 운영 장치:
  - 캐시: 그래프 서명 + 질문.
  - 사용자별 시간당 호출 한도: 환경 변수, 기본 30.
  - 비용 기록.
  - 키 값은 응답·로그에 0. `source_coverage`·`capability` 테스트 관용구를 쓴다.
- 기존 구멍을 같이 고친다: `claude_client` 의 "키 있음 + SDK 없음 = 데모 글을 정상처럼" → `error` 를 채운다.

### AI1~AI5

| | 무엇 | 입력 → 출력 | 화면 |
|---|---|---|---|
| AI1 노드 추천 | 다음에 붙일 노드 1~3 | 그래프 + 목표 → `[{kind, attach, reason}]` | 유령 노드 + 이유 한 줄 · [붙이기] |
| AI2 풀어 쓰기 | 계산 결과를 읽는 순서로 | `/run` explain 사실 → 문단 | 이야기 탭 위 "AI 가 풀어 쓴 글"(서버 사실 위에 · 숫자 검사) |
| AI3 묻기 | 노드·선에게 질문 | 고른 노드·선 사실 + 질문 → 답 | 묻기 칸 · 근거 칩(어느 사실을 썼나) |
| AI4 말로 설계 | 말 → 그래프 초안 | 문장 → 문서 초안 | 바뀐 점 미리보기(추가·연결·말씀에서 가져온 값) · [받아들이기]만 반영 · 되돌리기 한 번 |
| AI5 길잡이 | 도구를 적극 쓰게 | 상태(빈 캔버스·계산 전·관문 막힘·갈래 없음·견고성 안 봄…) + 기능 목록 → 다음에 써 볼 도구 1~2 | 아래 안내 줄 · "왜" 한 줄 · [해 보기] |

길잡이는 투자 판단을 말하지 않는다. "이 전략이 좋아요"는 금지다. 말하는 것은 "갈래를 만들면 두 설계를 나란히 비교할 수 있어요" 같은 도구 안내뿐이다.

## 5. 테스트·검증

- 1부 각 단계:
  1. E2E 를 먼저 써서 빨강을 확인한다(동작 단언 — 선 수 · 소켓 이름 보임 · 경유점 저장·복원 · 다시 꽂기 거부 사유 · 레인 맞추기 · 미니맵 · 실행 줄 순서).
  2. 구현한다.
  3. 변이 테스트를 한다.
  4. 전·후 PNG(라이트/다크 · 1440/390)를 보이고 허락받는다.
  5. 전체 게이트를 돈다.
  6. HISTORY 를 쓰고 커밋·푸시한다.
- 서버 `relations`: 문장 틀 · role 없음 짝 · 요약 없음 짝 · 금지 표현 · 순수성 · `waypoints` 무시(엔진 결과 바이트 같음).
- 2부: pytest 는 가짜 클라이언트를 주입한다.
  - 카탈로그 밖 노드 → 탈락 / 짝: 안 노드 → 통과.
  - 연결 위반 → 탈락.
  - 근거 밖 숫자 → 탈락 / 짝: 근거 숫자 → 통과.
  - 금지 표현 → 탈락.
  - 키 없음 → `available:false` + 규칙 대체이고, 데모 글이 없다.
  - 차단기 열림 · 한도 초과 · 키 값 누출 0.
- 키가 들어오면 실제 응답을 몇 번 관측해 HISTORY 에 적는다. 키가 없으면 "실제 응답 관측 못 함"으로 적는다.
- 변이 테스트(예): 숫자 검사 끄기 · 카탈로그 검사 끄기 · 키 없을 때 데모 글 · 관계 문장에 role 상수 · 경유점이 엔진 결과를 바꿈 · 다시 꽂기 검사 빼기.

## 6. 위험

- v12 이사로 E2E 의 `react-flow__*` 선택자나 동작이 달라질 수 있다 → CF0 을 단독 커밋으로 하고 변화 0 을 증명한 뒤 진행한다.
- 큰 노드 때문에 화면이 붐빈다 → 확대 3단 · 노드 접기 · 레인 보기 · 자동 정리로 줄인다. 기본 확대를 "중간"으로 시작할지는 CF1 PNG 를 보고 정한다.
- `PortfolioCanvas.tsx`·`store.ts` 비대 → 이번 작업에서 손대는 부분(선·연결·배경·컨트롤러)만 새 파일로 나눈다. 무관한 리팩터링은 하지 않는다.
- AI 비용·지연 → 캐시 · 한도 · 버튼을 눌러야만 부른다(자동 호출 없음, 길잡이도 버튼·상태 변화 뒤 한 번).
