# BJ · 엔드투엔드 퀀트 워크플로우 UX — 토스처럼 쉽게, 전문가는 끝까지 조절한다

작성 2026-09-25 · 앞 프로그램 BI(`2026-09-25-aas-node-canvas-design.md`) · 결정 기록 ADR 002

## 1. 왜

BI 가 AAS 를 노드 캔버스로 바꿨지만 사용자 판단은 *"UI 가 너무 안 좋다"* 였다. 설명가능성
계층을 감안해 **토스처럼 고객 친화적인** 화면으로, 그러면서도 **노드·링크를 자유롭게 조립**하고
**퀀트 전문가가 모든 파라미터를 조절**할 수 있게 한다. 노드 확장(스트레스·알파 …)보다 먼저 한다.

## 2. 사용자가 정한 것

| 결정 | 답 |
|---|---|
| 주 사용자 | 고객이 기본, 전문가도 — 노드·링크는 **자유 조립·조합** |
| 화면 구조 | **캔버스 + 이야기 패널**(A) + 전문가 **깊은 커스터마이징** |
| 설명 문장 | **서버가 결정적 규칙으로 만든다** — 화면은 그리기만 |
| 범위 | **AAS 캔버스부터**(토큰은 재사용 가능하게). 구현 전에 **예상 화면을 먼저 보여 준다** |

## 3. 조사에서 가져온 것

Composer(위→아래로 읽히는 문장형 전략) · n8n(노드의 입력·설정·출력을 나란히) · ComfyUI(타입
포트 — 그러나 위압감이 지금의 문제) · Dagster(계보 그래프의 상태 배지) · Hex·Observable(같은 DAG
의 두 렌즈) · 토스(한 화면 한 메시지 · 큰 숫자 · 해요체 · 쉬운 말). ★우리 쪽 예외★ — 쉬운 말이
미상을 가리면 안 된다. **쉬운 말로 "몰라요" 라고 말한다.**

## 4. 설계

### 4.1 화면 (목업 승인본 — 스크린샷 6장: 이야기 · 관문 사유 · 설정 기본 · 설정 고급 · 다크 · 노드 상태)

```
┌ 상단: 포트폴리오 설계 · [불러오기] [내보내기] [계산하기]      (예전 화면: 단계별 마법사) ┐
├ 증거 관문 레일 — "이 결과를 어디까지 믿을 수 있을까요"  8개 역, 건너뛴 구간은 선이 끊긴다 ┤
├ 팔레트(220) ─┬──────────── 캔버스(자유 조립, 왼→오) ────────────┬ 이야기|설정|자세히(384) ┤
```

- **하나의 강한 요소 = 증거 관문 레일.** CLAUDE.md 관문 순서의 8역(데이터 · 시점 · 신호 · 비중 계산
  · 거래비용 · 처음 보는 기간 · 돈이 되는지 · 모의·실계좌). 상태 5종 — 확인(채운 원) · 가정(속 빈
  주황) · 절반 확인(반원) · 몰라요(빗금) · 건너뜀(점선 원). **건너뛴 구간은 레일 자체가 끊긴다** —
  "건너뛴 관문은 통과한 관문이 아니다" 를 모양으로. 역을 누르면 쉬운 말 사유 목록(확인/몰라요 칩).
- **팔레트** — 워크플로우 단계(데이터 · 신호 · 생각 정하기 · 비중 정하기 · 확인하기)별 쉬운 이름 +
  한 줄 설명 + 검색 + 빠른 시작. 노드가 없는 단계는 "곧 추가돼요".
- **노드 카드** — 단계 색 번호 배지 · 쉬운 이름 · 실행 후 큰 숫자 하나(서버 headline) · 증거 칩 ·
  상태 점. 상태: 계산 전 · 완료 · 막힘("앞 단계 ‘수익률’이 실패해서 멈췄어요") · 실패 · 설정 확인 ·
  모르는 노드(빨간 점선) · 예전 결과(흐림 + "설정을 바꿔서 이 숫자는 예전 결과예요").
- **이야기 탭**(기본) — 노드 번호와 같은 번호의 단계 목록, 해요체 제목, 큰 숫자·막대, "믿어도
  되나요?" 상자(확인·가정·몰라요 칩 + 한 문장). 맨 위에 연습용 데이터 경고.
- **설정 탭** — 받는 것 / 내는 것(n8n 식) → 기본: 질문형 제목("어떤 방식으로 나눌까요?"), 선택
  카드, 슬라이더(과감하게 ↔ 신중하게), 프리셋 칩 · **전문가 설정 보기** 토글 → 모든 파라미터(쉬운
  이름 + 파라미터 키 + 범위·기본값) + 복합 칸 JSON.
- **자세히 탭** — 지금의 결과 패널(표·차트·원자료·성과 라벨).

### 4.2 시각 언어 (`--pg-*`, AAS 만)

| 이름 | 라이트 | 다크 | 쓰임 |
|---|---|---|---|
| paper / canvas | `#FFFFFF` / `#F4F6F9` | `#17191C` / `#101114` | 표면 / 캔버스 바탕(점 격자) |
| ink / body / mute / line | `#191F28` / `#4E5968` / `#8B95A1` / `#E5E8EB` | `#F2F4F6` / `#C1C7CF` / `#8B95A1` / `#2C3036` | 글자 계층·선 |
| blue | `#3182F6` | `#4D94FF` | 주 행동·선택 |
| 확인 / 가정 / 몰라요 / 실패 | `#0A7F57` / `#A15C00` / `#5B6573` / `#D92D3C` | `#3CCF91` / `#F5B453` / `#A3ACB8` / `#FF6B76` | 증거 상태 |

글꼴 **Pretendard**(한 가족, 숫자는 tabular) — 앱에는 npm 패키지를 로컬 폰트로 싣는다(외부 CDN
금지 환경). 크기 12·13·15·17·20·28·40. 대문자 라벨·모노 라벨·가운뎃점 메타 문자열을 쓰지 않는다.
반경: 카드 16, 입력 10, 칩 6. 움직임은 사용자 행동에 대한 응답만(펼침·선택), `prefers-reduced-motion`.

### 4.3 설명가능성 계층 — ★서버가 문장을 만든다★

- **카탈로그 UI 메타**(`allocation_graph_nodes.py`): 노드 `stage` · `plain_label` · `plain_description`,
  파라미터 `json_schema_extra={"x-ui": {label, help, tier: basic|advanced, presets, question}}`.
  팔레트·폼은 이것만 본다.
- **노드 `explain`**(신규 `src/api/allocation_graph_explain.py`, 순수): `{title, headline:{label,value,unit},
  facts[], trust:[{state, text}], unmeasured[]}`. 결정적 템플릿 · 해요체.
- **관문 판정**(신규 `src/domain/workflow_gates.py`, 순수): 그래프 구성 + 노드 provenance → 8 관문
  `{state: confirmed|assumed|partial|unknown|skipped|failed, reasons[{state,text}]}`. `run` 응답의 `gates`.
  mock(E0)이면 데이터 = 몰라요(연습용). 경제적 가치·모의/실계좌는 이 경로에 없으므로 건너뜀.
- **정직성 가드** — 금지어("검증됨·입증됨·견고함·프로덕션 레디·투자 우위·더 나은 전략") 전수 ·
  mock 이면 연습용 문구 필수 · 미상은 "몰라요"+사유(0·빈칸 금지) · 골든 · 짝(관문이 항상-확인/
  항상-건너뜀 구현 배제) · 변이.

## 5. 단계

BJ0 목업 승인(이 문서) → BJ1 서버 설명가능성(TDD) → BJ2 캔버스 재단장(토큰·노드 카드·팔레트·
관문 레일) → BJ3 이야기·설정·자세히 탭 → BJ4 검증(E2E·대비 감사·실물 대 목업 스크린샷)·문서.
노드 확장(스트레스·알파 …)은 BK 이후.

## 6. ★하지 않는 것★

앱 전체 디자인 교체 · 새 계산 노드 · AI 해설 · 계산·정책 변경 · 서버 저장 · 파라미터 스윕.
