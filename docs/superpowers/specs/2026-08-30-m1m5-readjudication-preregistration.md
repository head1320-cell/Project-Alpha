# M1~M5 재판정 — ★사전등록★ (A3, 2026-08-30)

> **실행 전에 커밋된다.** 원 사전등록(`13ba50a`)과 그 결과 기록은
> [`2026-08-29-macro-regime-negative-control-design.md`](2026-08-29-macro-regime-negative-control-design.md)
> 에 있고 ★한 글자도 고치지 않는다★. 여기서 하는 것은 **판정을 뒤집는 것이 아니라
> 그 판정이 무엇을 뜻했는지 정밀하게 하는 것**이다.

## 0. 왜 재판정하는가

M1~M5 는 `passed: false` 하나만 남겼다. 그 불리언은 **네 가지 다른 상황을 구별
하지 못한다** — 관문을 못 돌렸다 / 검정력이 없었다 / 두 관문이 엇갈렸다 / 찾을
힘이 있었는데 못 찾았다. A2 의 다섯 분류와 A1 의 검정력 산출이 그 구별을 준다.

## 1. ★라벨을 미리 정하지 않는다★

감사(`7313371` §5)와 승인된 계획이 둘 다 **`underpowered` 를 전제**했다. 그것은
전제일 뿐이다. 실행 전 읽기 전용 재현에서 M1~M5 를 그대로 다시 돌린 결과:

```
분위 100 / 100 / 100 (비용 5·10·25bps) → null_outside = True
SPA p_max = 0.105                      → spa_ok = False
→ classify(null_outside=True, spa_ok=False, ...) = inconclusive
```

두 관문이 **엇갈렸으므로** `inconclusive` 다. `underpowered` 는 **둘 다** 실패
했을 때의 라벨이다. ★규칙이 내지 않는 라벨을 붙이면 그것이 사후 합리화다.★
그러므로 이 재판정의 라벨은 **`decide_verdict` 가 내는 것을 그대로** 쓴다.

검정력은 그 위에서 **어느 성분이 병목이었는가**를 정량화한다.

## 2. 검정력 격자 (결과 전 고정)

- 척도 `(1.0, 2.0, 3.0, 4.0)` · 시드 **5개** · **84개월 고정**.
  ★개월 축은 넣지 않는다★(사용자 결정) — 결과가 병목을 지목하면 그때 별도로 답한다.
- `n_markov = 0, n_block = 0` — 두 보조 널은 `decisive: false` 라 **판정에 들어가지
  않는다**. 검정력 시행에서 빼면 264 백테스트로 줄어 1시행 ≈ 172초다.
  ★판정에 쓰이는 순환이동 널(전수 83)과 SPA(1000reps)는 그대로 둔다.★
- `spa_reps = 1000` · 목표 검정력 `0.80` · 임계 `(5.0, 95.0)` — 원 사전등록과 동일.

## 3. ★세 검정력을 함께 낸다★

같은 실행에서 공짜로 나온다. 어느 성분이 병목인지가 **프로그램의 다음 순서를
정한다**.

| 이름 | 정의 |
|---|---|
| `power_conjunction` | 널 밖 **and** SPA 유의 — 실제 판정 규칙 |
| `power_null_only` | 순환이동 널 밖만 |
| `power_spa_only` | SPA 유의만 |

**예측(결과 전에 적는다)**: 1× 에서 `power_null_only` 는 높고
`power_spa_only` 는 낮을 것이다 — 실측 재현에서 분위가 100 인데 SPA p 는 0.105
였기 때문이다. 즉 ★병목은 SPA 성분★ 이라고 예측한다. 연 Sharpe 차 0.20 을 약 6년
표본에서 재면 t ≈ 0.49 라 애초에 유의할 만한 표본이 아니다.
