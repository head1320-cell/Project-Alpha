# BS — BR "하지 않은 것" 마무리 설계 (2026-09-29)

사용자 지시: "하지 않은 것 중에 '머리 줄의 국면 줄'만 빼고 이어서 다 해". 계획 원본은 세션 계획 파일
(`happy-percolating-falcon.md`)이다. 이 문서는 **정한 것과 그 이유**만 남긴다.

## 사용자 결정 (AskUserQuestion)

| 질문 | 답 |
|---|---|
| 가입 방식 | **관리자가 계정 발급**. 공개 가입·초대 코드는 만들지 않는다. |
| 합치기 방법·몫 | **기본값은 그대로**. 고를 때만 쓰이는 방법을 더한다: 위기 상관 반영 · 엔진에 있는 방법 노출 · 몫 직접 정하기 · 탐색에서 찾은 더 나은 방법. CLAUDE.md §3 의 별도 승인 사항으로 사용자가 승인했다. |
| 카드 크기 | **내용에 맞춰 줄이기**(실측). 합치기 카드 236 > 열 230, `NODE_W` 176 ≠ 164 두 어긋남도 고친다. |

가입을 공개로 열지 않는 이유: 로그인만 하면 열리는 보호 라우트에 실계좌 잔고·주문 이력·일별 손익이 있다
(`src/api/protected_routes.py` 의 `REQUIRE_LOGIN` 항목들). 누구나 가입할 수 있으면 누구나 이것을 본다.

## BS1 · 계정 — 정한 것

- **보안 상태는 새 테이블 `user_security`** 에 둔다. `users` 에 열을 더하면 운영 DB 에 `ALTER` 가 필요하고, 실패하면 ORM 조회 전체가 깨진다.
  새 테이블은 `create_all` 이 만들고, 행이 없으면 기본값(판 0 · 바꿀 차례 아님)이다. 예전 계정은 그대로 로그인된다.
- **토큰 판(`tv`)**: 비밀번호를 바꾸거나 초기화하면 판이 1 오르고, 판이 다른 토큰은 `get_current_principal` 에서 401 이다.
  예전에는 비밀번호를 바꿔도 옛 토큰이 12시간 살았다. 사라진 계정의 토큰도 401 이다. 계정 DB 에 닿지 못하면 503 이다 —
  확인하지 못한 것을 통과로도 거절로도 접지 않는다.
- **처음 로그인**: 관리자가 준 임시 비밀번호로는 `require_login`·`require_admin`·`require_self_or_admin` 라우트가 403 이다.
  비밀번호 바꾸기(`require_login_to_change_password`)와 `/auth/me` 만 열린다.
- **비밀번호 규칙**(순수 `src/domain/password_policy.py`): 8자 이상 · 72바이트 이하(bcrypt 가 뒤를 자른다) · 지금과 다름 ·
  아이디와 다름 · 저장소가 만든 적 있는 값(`frm123!`·`temp`·`changeme`) 아님. 구성 규칙(대문자·특수문자)은 넣지 않았다
  (NIST SP 800-63B §5.1.1.2). 화면이 같은 규칙을 미리 보이고, 두 목록이 같은지는 pytest 가 본다.
- **지금 비밀번호를 5번 틀리면 15분 429**. 프로세스 로컬이다(`--workers 1`).
- **발급**: 임시 비밀번호는 서버가 만들고 응답에 한 번만 싣는다. 목록은 해시·비밀번호를 싣지 않는다.
- **admin 기본 비밀번호 상태는 계정을 본다**. 예전 판정은 환경변수만 봤다. 그 값은 admin 행을 처음 만들 때만 쓰이므로,
  "설정했지만 계정은 아직 기본값을 받는" 배포를 configured 라고 말했다.
- **옆문 계정**: `update_user_portfolio`·`log_trade` 가 비밀번호 `"temp"` 로 계정을 만들던 것을 아무도 모르는 비밀번호로 바꿨다.
- **로그**에는 이름만 남기고 비밀번호·토큰·임시 비밀번호는 남기지 않는다(caplog 테스트).
- **화면** `/settings`(`.set-*` = E2E 계약): 신원 머리 → (바꿀 차례면 안내) → 비밀번호 → 화면 테마 → (관리자) 계정 관리 → 로그아웃.
  토큰만 쓰므로 `DARK_READY` 에 들어간다. 세션·테마 모듈은 두 기능이 함께 쓰므로 `entities/session`·`shared/theme` 으로 내렸다
  (FSD: 같은 계층 슬라이스끼리 import 금지).

## 하지 않는 것

- 공개 가입·초대 코드 · 로그인 시도 제한(비밀번호 바꾸기에만 둔다)
- 합치기 몫을 정하는 흐름의 끝 맞춤을 날짜 맞춤으로 고치기 — 배분 경로 변경이라 관측·제안만 한다(BS3)
- 실거래 전략 기록(저장소에 없다) · 첫 화면(`/`)의 다크 · 늘 어두운 관리 화면 셋의 라이트화 · 머리 줄 국면 줄
