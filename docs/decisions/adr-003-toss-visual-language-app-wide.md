# ADR 003 — 토스식 시각 언어를 앱 전체로 (캔버스 밖 탭)

- 상태: 채택 (2026-10-01)

- 스펙: [`docs/superpowers/specs/2026-09-30-bu-toss-app-wide-design.md`](../superpowers/specs/2026-09-30-bu-toss-app-wide-design.md)

## 1. 무엇을 정정하나

세 기록이 "토스식은 캔버스 안에만"이라고 정했다. 사용자 지시로 셋 다 정정한다.

| 기록 | 원래 문장 | 정정 |
|---|---|---|
| ADR-001 §2.2 | "institutional, data-dense" — 촘촘한 간격 · mono/sans 짝 · 장식 그림자 없음 · 큰 카드 여백 없음 | 캔버스 밖 탭도 **토스식**으로 간다: 회색 바탕 위 흰 절, 반경으로 위계, 해요체, 고정폭은 **식별자에만**. "장식 그림자 없음"은 유지한다(절은 그림자 없이 바탕 대비로 뜬다). |
| ADR-002 :82 | "시각 언어는 `.pg-theme` 안에만(사이트 크롬은 그대로)" | 사이트 크롬(셸)부터 `--tx-*` 로 바꾼다. 값은 `--pg-*` 와 같게 두어 한 제품으로 보이게 한다. |
| BJ 스펙 §6 | "하지 않는 것: 앱 전체 디자인 교체" | BJ 범위에서는 맞았다. 이번 BU 가 그 일을 **모듈 단위로** 한다. |

## 2. 무엇을 유지하나 (바꾸지 않는다)

1. **CSS 클래스는 E2E 계약이다.** 기존 클래스는 지우거나 이름을 바꾸지 않는다. 새 구조에는 새 클래스(`tx-*`)를
   붙이고, 문구를 단언하던 스펙은 같은 커밋에서 고친다.
2. **`globals.css` 의 `:root` 네 블록은 바이트 그대로다.** 새 토큰은 파일 **끝**의 새 블록에 두고, 그 바로 뒤에
   `.dark` 짝을 둔다(새 `:root` 가 앞선 `.dark` 를 덮지 않게).
3. **번들 예산**(ADR-001 §Amendment)은 첫 로드 JS 로 잰다. 글꼴 CSS 는 JS 가 아니므로 **따로 재서** 커밋에 적는다.
4. **툴팁 금지.** 사유는 보이는 줄에 둔다.
5. **모듈 단위 전환.** 한 커밋이 셸과 여러 모듈을 함께 바꾸지 않는다. 라이트 골든은 범위별 diff
   (`scripts/golden-diff.mjs`)로 그 커밋이 건드린 범위만 바뀌었는지 확인한 뒤 다시 뜬다.
6. **답 문장 = 서버 값.** 화면 맨 위의 한 문장은 서버 필드를 정해진 틀에 끼운 것이다. 클라이언트 임계값으로
   새 판단("조심하세요")을 만들지 않는다. 판단 필드가 없으면 잰 값만 말한다("스트레스 52/100이에요").
   허용되는 클라이언트 일: 서버 열거값 번역 · 숫자·단위 서식 · 필드를 틀에 끼우기.
7. **관리 화면 셋은 보이는 것만.** 요청(메서드·경로·본문)·확인 단계·폴링 주기·`ConfirmModal` 구조는 바꾸지
   않는다. 바꾸기 전에 요청 골든을 얼리고 바꾼 뒤 바이트 동일을 확인한다. `src/` diff 는 0 이어야 한다.
8. **금지 표현**(검증됨·입증됨·견고함·프로덕션 레디·투자 우위·더 나은 전략)은 화면 글자에도 걸린다
   (`tests/test_frontend_claim_words.py`, BU0b).

## 3. 색 규칙 (새로 정한 것)

- `--tx-up #f04452` / `--tx-down #3182f6` 은 **등락·수익률·델타에만** 쓴다(한국식). 늘 부호(+/−)와 함께 쓴다 —
  색만으로 말하지 않는다. 두 색은 흰 바탕 위 3.71:1 이라 그래프·큰 숫자에만 쓰고, 글자는 `--tx-up-ink #d22a3b` /
  `--tx-down-ink #1b64da`(4.5:1 이상)를 쓴다.
- 상태(실패·위험)는 `--tx-danger` + 아이콘·문구다. 판정 칩(저평가 등)은 등락이 아니므로 중립 색조다.
- 전역 `--color-bull/bear` 는 뒤집지 않는다 — 등락과 오류 상태에 함께 쓰여 있어서, 모듈 단계마다 쓰임별로 옮긴다.
- `--t-accent #1200ff` 도 전역으로 덮지 않는다(소비처가 모든 모듈에 걸쳐 있다). 셸은 `--tx-*` 만 쓰고,
  각 모듈은 제 단계에서 옮기며, 남은 것은 BU10 정리에서 걷는다.

## 4. 결과

- 장점: 캔버스·설정·프로필(이미 토스식)과 나머지 탭이 한 제품으로 보인다. 화면마다 "답 한 문장 + 근거 칩"이
  설명가능성(CLAUDE.md ③)을 앱 전체의 시각 언어로 만든다.
- 비용: 모듈마다 라이트 골든을 다시 뜨고 문구 단언을 고친다. 전환 기간에는 셸(토스식)과 아직 안 바꾼 모듈
  (터미널식)이 한 화면에 함께 보인다 — 모듈 단위 전환의 대가로 받아들인다.
- Pretendard CSS(@font-face 92개, 약 56 KB)가 모든 라우트에 붙는다. woff2 는 필요한 글자 범위만 받는다.
