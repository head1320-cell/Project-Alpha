# ADR 002 — AAS 는 노드 캔버스가 된다

- 상태: **Accepted** (2026-09-25, 사용자 결정 — 스펙 `docs/superpowers/specs/2026-09-25-aas-node-canvas-design.md`)
- 관련: [ADR 001](adr-001-tailwind-shadcn-aas-migration.md)(스타일·번들 예산·E2E 클래스 계약)

## 1. 결정

1. `/allocation` 의 본체는 **노드-링크 캔버스**다(reactflow). 10단계 마법사는 도구가 노드로
   옮겨지는 만큼 걷는다 — 한 번에 지우지 않는다(스펙 §4.6).
2. 그래프는 **백엔드**가 실행한다(`POST /api/v1/allocation/graph/run`). 캔버스는 편집기이고
   계산을 하지 않는다 — 노드는 `/analyze`·`/backtest` 와 **같은 함수**를 부른다.
3. 저장은 **파일 포맷 `project-alpha.portfolio-graph` v1** 이 계약이다. 지금은 내보내기·
   불러오기만, 서버 저장은 같은 포맷으로 나중에.
4. E2E 계약 클래스는 **`.pg-*`**. `.aas-*`·`.as-*` 는 해당 화면이 걷힐 때 그 스펙과 함께 걷힌다.

## 2. 번들 예산 (ADR 001 개정)

ADR 001 의 ≥4 kB·15 kB 선은 **항상 뜨는 표면**에 걸린다. 캔버스는 `/allocation` 에서 항상 뜨는
**본체**라 "열 때만 로드" 예외에 들지 않고, reactflow 만으로 15 kB 선을 넘는다.

- ★이 라우트는 예산을 **다시 잡는다**★ — 캔버스 도입 커밋이 전/후 첫 로드 표를 커밋 메시지와
  HISTORY 에 남기고, 그 값이 `/allocation` 의 새 기준선이 된다. 이후 변화는 ADR 001 의 선을
  그대로 따른다.
- 캔버스는 `next/dynamic`(ssr: false)로 싣는다 — 페이지 골격·오류 표면이 캔버스 청크보다 먼저 뜬다.
- 다른 AAS 라우트는 예산이 바뀌지 않는다.

## 3. 대안

- **마법사 유지 + 캔버스 병설** — 사용자가 교체를 골랐다.
- **프런트가 노드마다 기존 API 호출** — `/analyze` 가 뭉쳐 있어 노드 경계가 가짜가 되고
  재현성이 약하다. 거절.
- **기존 `dag_runner` 스키마 확장** — 단일 종목 신호 전용이고 합성 경로(`_generate_gbm`)가 있어
  포트폴리오 타입과 섞으면 백테스트 탭 동작이 바뀐다. 패턴만 재사용.

## 4. 결과

- 노드별 출처·등급·미상 사유가 한 실행 응답에 모인다(설명가능성 축).
- 마법사와 캔버스가 공존하는 기간에는 두 표면이 같은 포트폴리오를 다룬다 — 캔버스→세션 다리
  여부는 BI4 감사에서 확정해 이 ADR 에 덧붙인다.

## 5. 덧붙임 (BI3·BI4, 2026-09-25) — 게이트 이동 · 넘기기 · 번들 실측

**사용자 결정: 마법사는 전체 보존, 캔버스에서 마법사 도구로 넘긴다.** 그래서:

- 마법사 게이트(목표 선택)는 `/allocation/wizard` 로 옮겼다. `CANVAS_HREF`·`WIZARD_GATE_HREF`
  (`widgets/allocation/AllocationProvider.tsx`)가 두 입구의 단일 출처이고
  `isKnownAllocationRoute` 가 둘 다 안다. 게이트를 기대하던 E2E 22곳은 진입 경로만 바꿨다.
- **넘기기는 숫자가 아니라 입력이다.** 캔버스 옵티마이저가 성공하면 종목(수익률 노드가 실제로
  남긴 것)·현재 비중(없으면 균등, %)·`assets` 형식 뷰·**실제로 쓴** 모델·δ·τ·제약을 마법사 세션
  세터로 넣고, 다음 렌더에서 마법사의 `ensureFreshRun` 을 불러 **같은 `/analyze`** 로 다시
  구한다. E2E 가 마법사 세션을 다른 δ·τ 로 미리 채운 상태에서 두 최적 비중이 같음을 건다.
  마법사 세션에 자리가 없는 설정(lookback·as_of·벤치마크·추정 설정·조합 뷰)은 **넘기기 전에**
  "넘어가지 않습니다" 목록으로 보인다.
- 세션 세터를 부르는 것은 app 계층(`app/allocation/page.tsx`)이다 — 위젯끼리는 import 하지
  않는다(FSD). 역방향(마법사 → 캔버스)은 없다.

**번들 (First Load JS, `next build`)** — 캔버스는 `next/dynamic`(ssr:false)라 첫 로드에서 빠졌다.

| 라우트 | 전 | 후 |
|---|---|---|
| `/allocation` | 129 kB (게이트) | **119 kB** (캔버스 골격; reactflow 는 캔버스 청크) |
| `/allocation/wizard` | — | 129 kB (옮긴 게이트, 전과 같다) |
| 나머지 AAS 스테이지 11개 | 115~263 kB | 각 +0~1 kB (공용 청크, 4 kB 선 아래) |
| `/backtest` · `/macro` | 128 · 246 kB | 128 · 247 kB |

`/allocation` 의 새 기준선은 **119 kB**다.
